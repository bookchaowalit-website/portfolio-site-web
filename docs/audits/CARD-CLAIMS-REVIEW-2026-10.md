# Card claims review (2026-10-21)

Every card in `src/data/app-projects.ts` was checked against the code of the repository it describes
(latest default branch: README/PRODUCT.md, package.json, pages, API routes and data files), plus the
roadmap `purpose` and `observed_gaps` in the hub's `repository-catalog/roadmaps/*.yaml`. Claims of a
backend, database, integration, AI model, sync, payments or adoption that the code does not ship were
removed, and `evidenceLevel` now says what the card is: `Prototype` for client-only demos over sample
or browser-local data, `Live` for working tools or products with real content or a backend,
`Internal System` for operator tooling, `Experiment` for empty or retired pages.

Links: each card now carries its canonical `repo` (`owner/name`) and `githubUrl` is built from it
(`gh()`), following `repository-catalog/registries/vercel-projects.yaml` and
`portfolio/BOOK-DEV-CANONICAL-TWINS.md`. Cards whose repository is private, archived-private or gone carry
no repo and publish no source link. The 17 single-tool devtools repositories were archived into
`bookchaowalit-website/devtools-suite-web`, so those cards link the suite and its route.
Link results are in [LIVE-LINK-AUDIT-2026-10.md](LIVE-LINK-AUDIT-2026-10.md).
Regression tests: `src/data/__tests__/source-links.test.ts` and the "portfolio claims" block in
`src/data/__tests__/portfolio-catalog.test.ts`.
